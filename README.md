# GTU Diploma Electrical Syllabus Archive

A permanent archive of Gujarat Technological University (GTU) Diploma in Engineering, Electrical Engineering (branch 09) teaching schemes: every subject code, subject name, category, lecture/tutorial/practical hours, credits and marks breakup, for every scheme and semester available on the official GTU syllabus portal.

Archived from the official portal (old26.gtu.ac.in/Syllabus/Syllabus.aspx) starting 2026-11-01, so the record survives even if the portal changes or removes old schemes.

Notes on the portal data: the 2011 scheme's Semester 1-2 lists are the common first-year pool shared across all diploma branches, exactly as the portal returns them for branch 09. The new DI scheme's Semester 6 is not yet published on the portal. Some diploma academic-year selections (2018-19, 2020-21) return no rows on the portal even though the subjects exist in the unfiltered lists, so this archive is built from both year-anchored and unfiltered portal searches.

## Columns

L = Lectures, T = Tutorial, P = Practical, PBL = Project Based Learning, E = External theory marks, M = Internal assessment, I = Internal viva/submission, V = External viva, Total = total marks. Values are exactly as shown on the GTU portal.
